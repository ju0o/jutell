# 코드 리뷰 요청서

> 작성법: `[ ]`에 체크하고, 빈칸은 쉬운 말로 채웁니다. 모르는 항목은 비워 두세요.

## 1. 지금 만들고 있는 것

리뷰할 작업이 속한 프로젝트나 화면을 한두 문장으로 설명해 주세요.

```
(예: 메모를 저장하고 목록으로 보여주는 앱)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 2. 이번에 무엇을 바꿨나요?

이번 작업에서 무엇을 만들거나 바꿨는지 적어 주세요.

```
(예: 메모 검색 기능을 추가했다)
```

- [ ] 잘 모르겠음 (AI가 최근 변경을 확인해 정리해 주세요)
- [ ] AI가 먼저 확인 후 제안

## 3. 어떤 점을 검토받고 싶나요?

중점적으로 확인받고 싶은 것을 고르세요. 여러 개 골라도 됩니다.

- [ ] 기존 기능이 망가지지 않았는지
- [ ] 실수나 오타가 없는지
- [ ] 만들어진 결과가 요청한 것과 같은지
- [ ] 나중에 문제가 될 만한 부분이 있는지
- [ ] 더 간단하게 만들 수 있는지
- [ ] 정확히 무엇을 확인해야 할지 모르겠음 (AI가 제안)

## 4. 반드시 유지할 부분

이번 작업에서 지금 있는 것 중 없어지면 안 되는 것을 적어 주세요.

```
(예: 기존 저장된 메모는 그대로 보존)
```

- [ ] 현재 상태 유지
- [ ] 요청하지 않음

## 5. 바꾸면 안 되는 부분

리뷰나 수정에서 건드리면 안 되는 것을 적어 주세요.

```
(예: 아직 공개하지 않을 화면은 건드리지 않는다)
```

- [ ] 요청하지 않음

## 6. 사용자가 직접 확인할 부분

리뷰 뒤 사용자가 직접 눌러 보거나 확인해야 하는 것을 적어 주세요.

```
(예: 검색이 실제로 잘 동작하는지)
```

- [ ] 요청하지 않음

## 7. AI가 먼저 확인할 질문

- [ ] AI가 먼저 어떤 파일이 바뀌었는지 확인하고 정리해 주세요.
- [ ] 실행 가능한 테스트나 점검 명령을 먼저 확인해 실행해 주세요.
- [ ] 발견한 문제를 위험한 순서대로 정리해 주세요.
- [ ] AI가 먼저 확인 후 제안 (위 항목 대신 AI 판단에 맡김)

## 8. 최종 요청문

아래를 복사해서 사용 중인 AI Agent에 붙여넣으세요. `( )` 자리에 위 내용을 합쳐서 적어도 됩니다.

```text
이 프로젝트의 최근 작업을 리뷰해주세요.

[바꾼 내용] (2번 항목 내용)
[검토할 항목] (3번 항목에서 고른 것들)
[유지할 부분] (4번 항목, 없으면 "없음")
[건드리면 안 되는 부분] (5번 항목, 없으면 "없음")
[사용자 확인] (6번 항목, 없으면 "없음")

체크되지 않은 항목은 비워 두었습니다.
먼저 어떤 파일이 바뀌었는지 확인한 뒤 검토해주세요.
확인하지 못한 사실은 추측으로 단정하지 말고 "확인 필요"로 표시해주세요.
중요한 문제는 위험한 순서로 정리해주세요.
```
