# 프로젝트 계획 요청서

> 작성법: `[ ]`에 체크하고, 빈칸은 쉬운 말로 채웁니다. 모르는 항목은 비워 두세요.

## 1. 만들고 싶은 것

만들고 싶은 서비스나 앱을 한두 문장으로 설명해 주세요.

```
(예: 가족끼리 할 일을 나누고 완료 여부를 확인하는 앱)
```

- [ ] 잘 모르겠음 (바꾸고 싶은 불편한 점은 있는데 형태를 정하지 못함)
- [ ] AI가 먼저 확인 후 제안

## 2. 지금 무엇이 불편한가요?

이것이 있으면 해결될 만한 일상의 불편함을 적어 주세요.

```
(예: 메신저로 할 일을 주고받으면 누가 뭘 했는지 헷갈린다)
```

- [ ] 정확히 무엇이 문제인지 모르겠음
- [ ] 잘 모르겠음

## 3. 원하는 결과와 우선순위

가장 먼저 꼭 되어야 하는 것부터 순서대로 적어 주세요. 많아도 5개를 넘지 않게 고르세요.

```
1. (예: 할 일을 추가할 수 있다)
2. (예: 가족 구성원별로 누가 했는지 표시된다)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안 (가능한 범위를 나눠서 제안해 주세요)

## 4. 누가 사용하나요?

누가 어떤 상황에서 쓰는지 적어 주세요.

```
(예: 가족 4명이 휴대폰으로 매일 사용)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 5. 반드시 유지할 부분

지금 사용 중인 것 중 이 계획에서 유지해야 하는 것을 적어 주세요. (기존 방식, 기존 자료 등)

```
(예: 지금까지 기록한 내용은 그대로 유지되어야 한다)
```

- [ ] 현재 상태 유지
- [ ] 요청하지 않음

## 6. 바꾸면 안 되는 부분

이번 계획에서 건드리면 안 되는 것을 적어 주세요.

```
(예: 가족 정보는 외부에 저장하지 않는다)
```

- [ ] 요청하지 않음

## 7. 사용자가 직접 확인할 부분

계획을 검토할 때 사용자가 직접 확인해야 하는 것을 적어 주세요.

```
(예: 휴대폰에서도 편하게 보이는지)
```

- [ ] 요청하지 않음

## 8. AI가 먼저 확인할 질문

- [ ] AI가 먼저 지금 프로젝트가 어떻게 구성되어 있는지 확인하고 계획을 세워 주세요.
- [ ] 어디까지 먼저 만들고 나중에 만들지 단계로 나눠 제안해 주세요.
- [ ] 예상되는 어려운 점이나 외부 도구가 필요한 부분을 미리 알려주세요.
- [ ] AI가 먼저 확인 후 제안 (위 항목 대신 AI 판단에 맡김)

## 9. 최종 요청문

아래를 복사해서 사용 중인 AI Agent에 붙여넣으세요. `( )` 자리에 위 내용을 합쳐서 적어도 됩니다.

```text
이 프로젝트에 대해 다음 계획을 세워주세요.

[만들고 싶은 것] (1번 항목 내용)
[불편한 점] (2번 항목 내용)
[우선순위] (3번 항목 내용)
[사용자] (4번 항목 내용)
[유지할 부분] (5번 항목, 없으면 "없음")
[건드리면 안 되는 부분] (6번 항목, 없으면 "없음")
[사용자 확인] (7번 항목, 없으면 "없음")

체크되지 않은 항목은 비워 두었습니다.
먼저 현재 프로젝트 구조를 확인하고, 작은 단계부터 나눈 계획을 제안해주세요.
계획을 확정하기 전에 필요한 정보가 있으면 질문해주세요.
```
