# 기능 요청서

> 작성법: `[ ]`에 체크하고, 빈칸은 쉬운 말로 채웁니다. 모르는 항목은 비워 두세요.

## 1. 지금 만들고 있는 것

지금 만들고 있는 화면이나 프로젝트를 한두 문장으로 설명해 주세요.

```
(예: 메모를 저장하고 목록으로 보여주는 앱)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 2. 무엇이 불편한가요?

지금 없어서 불편한 점이나 하고 싶은데 못 하고 있는 일을 적어 주세요.

```
(예: 메모가 많아지면 원하는 메모를 찾기 어렵다. 검색이 필요하다)
```

- [ ] 정확히 무엇이 문제인지 모르겠음
- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 3. 원하는 결과

새 기능이 생기면 무엇이 가능해지길 원하는지 적어 주세요.

```
(예: 제목이나 내용으로 메모를 찾을 수 있다)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 4. 반드시 유지할 부분

이번 기능을 추가해도 지금 있는 것 중 없어지면 안 되는 것을 적어 주세요.

```
(예: 기존 메모 저장 방식은 그대로 유지)
```

- [ ] 현재 상태 유지
- [ ] 요청하지 않음

## 5. 바꾸면 안 되는 부분

이번 요청에서 건드리면 안 되는 것(다른 화면, 다른 기능, 설정 등)을 적어 주세요.

```
(예: 기존 저장된 메모는 지우거나 형식을 바꾸지 않는다)
```

- [ ] 요청하지 않음

## 6. 사용자가 직접 확인할 부분

기능을 만든 뒤 사용자가 직접 눌러 보거나 확인해야 하는 것을 적어 주세요.

```
(예: 검색 결과가 실제 저장된 메모와 맞는지)
```

- [ ] 요청하지 않음

## 7. AI가 먼저 확인할 질문

- [ ] AI가 먼저 지금 프로젝트 구조와 기존 화면을 확인한 뒤 어디에 추가하는 게 좋은지 제안해 주세요.
- [ ] 필요한 기술이나 외부 도구가 있는지 먼저 확인해 주세요.
- [ ] 작업 전 계획과 검증 방법을 먼저 알려주세요.
- [ ] AI가 먼저 확인 후 제안 (위 항목 대신 AI 판단에 맡김)

## 8. 최종 요청문

아래를 복사해서 사용 중인 AI Agent에 붙여넣으세요. `( )` 자리에 위 내용을 합쳐서 적어도 됩니다.

```text
이 프로젝트에 다음 기능을 추가해주세요.

[불편한 점] (2번 항목 내용)
[원하는 결과] (3번 항목 내용)
[유지할 부분] (4번 항목, 없으면 "없음")
[건드리면 안 되는 부분] (5번 항목, 없으면 "없음")
[사용자 확인] (6번 항목, 없으면 "없음")

체크되지 않은 항목은 비워 두었습니다.
모르는 항목을 추측해 채우지 말고, 필요한 것이 있으면 먼저 질문해주세요.
작업 전 계획을 먼저 보여주고, 검증 방법(테스트·확인)을 함께 안내해주세요.
```
