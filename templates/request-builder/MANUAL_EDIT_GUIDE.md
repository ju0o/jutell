# 직접 파일 수정 안내 요청서

> AI가 만든 결과물을 사용자가 직접 파일에서 확인하거나 수정해야 할 때 사용합니다.
> 작성법: `[ ]`에 체크하고, 빈칸은 쉬운 말로 채웁니다. 모르는 항목은 비워 두세요.

## 1. 지금 만들고 있는 것

수정할 파일이 속한 프로젝트나 화면을 한두 문장으로 설명해 주세요.

```
(예: 메모를 저장하고 목록으로 보여주는 앱)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 2. 무엇을 확인하거나 수정하나요?

어떤 결과물을 어떤 이유로 직접 확인하거나 수정하고 싶은지 적어 주세요.

```
(예: 만든 화면의 색상 값을 직접 바꿔보고 싶다)
```

- [ ] 정확히 무엇을 바꿔야 할지 모르겠음
- [ ] 잘 모르겠음

## 3. 원하는 결과

수정하면 어떻게 되어야 하는지 적어 주세요.

```
(예: 화면의 기본 색상을 현재보다 더 차분한 색으로 바꾼다)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 4. 반드시 유지할 부분

수정 중 지금 있는 것 중 없어지면 안 되는 것을 적어 주세요.

```
(예: 저장된 데이터 형식은 그대로 유지)
```

- [ ] 현재 상태 유지
- [ ] 요청하지 않음

## 5. 바꾸면 안 되는 부분

이번 수정에서 건드리면 안 되는 것을 적어 주세요.

```
(예: 다른 기능의 코드는 건드리지 않는다)
```

- [ ] 요청하지 않음

## 6. 사용자가 직접 확인할 부분

수정 뒤 사용자가 직접 확인해야 하는 것을 적어 주세요.

```
(예: 실행했을 때 화면이 정상으로 보이는지)
```

- [ ] 요청하지 않음

## 7. AI가 먼저 확인할 질문

- [ ] AI가 먼저 어떤 파일을 열어야 하는지 실제 프로젝트에서 확인해 안내해 주세요.
- [ ] 어느 위치를 어떻게 고치면 되는지 한눈에 보이게 안내해 주세요.
- [ ] 수정할 때 주의할 점(되돌리는 방법 포함)을 알려주세요.
- [ ] 수정이 데이터 손실이나 보안과 관련되면 먼저 알려주세요.
- [ ] AI가 먼저 확인 후 제안 (위 항목 대신 AI 판단에 맡김)

## 8. 최종 요청문

아래를 복사해서 사용 중인 AI Agent에 붙여넣으세요. `( )` 자리에 위 내용을 합쳐서 적어도 됩니다.

```text
이 프로젝트에서 다음 내용을 사용자가 직접 확인/수정할 수 있게 안내해주세요.

[확인/수정할 내용] (2번 항목 내용)
[원하는 결과] (3번 항목 내용)
[유지할 부분] (4번 항목, 없으면 "없음")
[건드리면 안 되는 부분] (5번 항목, 없으면 "없음")
[사용자 확인] (6번 항목, 없으면 "없음")

먼저 실제 프로젝트에서 대상 파일을 확인한 뒤 위치를 알려주세요.
파일 경로와 수정 위치는 확인한 내용만 기준으로 안내하고,
확인하지 못한 경로는 "확인 필요"로 표시해주세요.
수정 전 되돌리는 방법과 주의점을 먼저 알려주세요.
```
