# 다음 Agent에게 작업 넘기기

> 이 템플릿은 지금까지의 작업 내용을 다음 AI Agent(또는 새 대화)에 전달할 때 사용합니다.
> 작성법: `[ ]`에 체크하고, 빈칸은 쉬운 말로 채웁니다. 모르는 항목은 비워 두세요.

## 1. 지금 만드는 것

프로젝트와 지금 만들고 있는 화면이나 기능을 한두 문장으로 설명해 주세요.

```
(예: 메모를 저장하고 목록으로 보여주는 앱의 검색 기능)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 2. 지금까지의 작업 요약

이미 무엇을 했는지, 지금 어디까지 되어 있는지 적어 주세요.

```
(예: 메모 저장과 목록 표시까지 완료했고, 검색 기능을 만들던 중이다)
```

- [ ] 잘 모르겠음 (AI가 현재 상태를 확인해 정리해 주세요)
- [ ] AI가 먼저 확인 후 제안

## 3. 지금 문제가 되는 것

지금 막혀 있거나 잘 안 되는 것을 적어 주세요.

```
(예: 검색 결과가 최신 메모부터 나오지 않는다)
```

- [ ] 정확히 무엇이 문제인지 모르겠음
- [ ] 요청하지 않음 (막힌 것 없음)

## 4. 다음에 할 일

다음에 이어서 해야 할 일을 순서대로 적어 주세요. 없으면 비워 두세요.

```
1. (예: 검색 결과 정렬을 수정)
2. (예: 검색 기록 화면 추가)
```

- [ ] 요청하지 않음 (아직 정하지 못함)
- [ ] AI가 먼저 확인 후 제안

## 5. 반드시 유지할 부분

이전 작업에서 지켜야 하는 방식이나 지우면 안 되는 것을 적어 주세요.

```
(예: 저장 방식과 파일 위치는 그대로 유지)
```

- [ ] 현재 상태 유지
- [ ] 요청하지 않음

## 6. 바꾸면 안 되는 부분

다음 작업에서 건드리면 안 되는 것을 적어 주세요.

```
(예: 결제 관련 코드는 건드리지 않는다)
```

- [ ] 요청하지 않음

## 7. 사용자가 직접 확인할 부분

다음 작업 후 사용자가 직접 눌러 보거나 확인해야 하는 것을 적어 주세요.

```
(예: 검색 결과가 실제 저장된 메모와 맞는지)
```

- [ ] 요청하지 않음

## 8. AI가 먼저 확인할 질문

- [ ] AI가 먼저 현재 프로젝트 상태를 확인한 뒤 "지금 상황 요약"을 알려주세요.
- [ ] 이전 작업에서 남은 미완료 항목을 확인해 목록으로 보여주세요.
- [ ] 전달받은 내용 중 빠진 것이 있는지 질문해 주세요.
- [ ] AI가 먼저 확인 후 제안 (위 항목 대신 AI 판단에 맡김)

## 9. 최종 요청문

아래를 복사해서 다음 AI Agent에 붙여넣으세요. `( )` 자리에 위 내용을 합쳐서 적어도 됩니다.

```text
이 프로젝트의 작업을 이어서 맡아주세요.

[프로젝트] (1번 항목 내용)
[지금까지 한 것] (2번 항목 내용)
[지금 문제] (3번 항목 내용, 없으면 "없음")
[다음에 할 일] (4번 항목 내용, 없으면 "없음")
[유지할 부분] (5번 항목, 없으면 "없음")
[건드리면 안 되는 부분] (6번 항목, 없으면 "없음")
[사용자 확인] (7번 항목, 없으면 "없음")

먼저 현재 상태를 확인하고 "지금 상황 요약"부터 알려주세요.
확인하지 못한 내용은 추측하지 말고 질문해주세요.
```
