# 다음 AI에게 전달하기

> 지금까지의 작업을 다음 AI Agent(또는 새 대화)에 넘길 때 쓰는 가벼운 전달문입니다.
> 현재 작업/세션에서 **이미 아는 근거만** 채웁니다. 저장소를 다시 읽거나, 테스트를 다시 돌리거나, 자동으로 다른 Agent에 보내지 않습니다.
> 모르는 항목은 비워 두거나 "확인하지 못함"으로 적습니다. Markdown 텍스트만 복사해서 사용합니다.

## 지금 하던 일

```
(예: 메모 앱 검색에서 빈 입력 검색을 막는 작업)
```

## 방금 끝난 것

```
(예: 빈 검색어 가드와 관련 테스트를 반영함)
```

## 확인된 것

```
(예: 단위 테스트 통과. 검색어가 공백이면 요청이 나가지 않음)
```

## 아직 확인하지 못한 것

```
(예: 실제 브라우저에서 검색 버튼 동작은 직접 확인하지 않음)
```

## 다음에 해줬으면 하는 것

```
1. (예: 검색 결과 정렬을 최신순으로 맞추기)
2. (예: 빈 입력 UI 안내 문구 추가)
```

## 먼저 보면 좋은 파일

```
- (예: src/features/search/SearchBar.tsx)
- (예: src/features/search/SearchBar.test.tsx)
```

## 건드리면 안 되는 것 (해당할 때만)

```
(예: 결제·인증 관련 코드는 건드리지 않는다)
```

## 사용자 결정이 필요한 것 (해당할 때만)

```
(예: 빈 검색 안내 문구를 어떤 말로 할지)
```
