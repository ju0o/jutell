- [ ] AI가 먼저 확인 후 제안

## 2. 어떤 문제가 있나요?

무엇이 어떻게 이상한지 있는 그대로 적어 주세요. 어디서부터 잘못됐는지 몰라도 괜찮습니다.

```
(예: 검색 버튼을 눌러도 아무 반응이 없다)
```

- [ ] 정확히 무엇이 문제인지 모르겠음 (어떤 점이 이상한지 느껴지지만 특정하지 못함)

## 3. 언제 문제가 생기나요?

문제가 생기는 상황을 가능한 한 자세히 적어 주세요. 기억나는 순서대로 적으면 됩니다.

```
(예: 검색어를 입력하고 Enter를 누르면 화면이 멈춘다. 몇 초 뒤 다시 동작한다)
```

- [ ] 항상 발생함
- [ ] 가끔 발생함
- [ ] 특정 조건에서만 발생함 (아래에 조건을 적어 주세요)

```

```

(예: 버튼을 누르면 바로 검색 결과가 보인다)

- [ ] 잘 모르겠음 (AI가 원래 의도된 동작을 확인해 알려주기)

- [ ] 원인을 못 찾으면 어떤 정보가 더 필요한지 알려주세요.
