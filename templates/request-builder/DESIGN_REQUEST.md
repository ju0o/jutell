# 디자인 요청서

> 작성법: `[ ]`에 체크하고, 빈칸은 쉬운 말로 채웁니다. 모르는 항목은 비워 두세요.

## 1. 지금 만들고 있는 것

지금 만들고 있는 화면이나 프로젝트를 한두 문장으로 설명해 주세요.

```
(예: 사용자가 검색어를 입력하면 결과를 보여주는 화면)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 2. 무엇이 불편한가요?

디자인에서 불편하거나 마음에 안 드는 영역을 고르세요. 여러 개 골라도 됩니다.

- [ ] 전체 분위기
- [ ] 색상
- [ ] 글씨
- [ ] 버튼
- [ ] 카드나 박스
- [ ] 화면 배치
- [ ] 여백
- [ ] 모바일 화면
- [ ] 정확히 무엇이 문제인지 모르겠음

구체적으로 어떤 점이 불편한지 적어 주세요. 화면의 색상 이름이나 코드를 몰라도 됩니다.

```
(예: 버튼이 작아서 눌리기 어렵다, 화면이 왼쪽으로 치우쳐 있다)
```

- [ ] 잘 모르겠음
- [ ] AI가 먼저 확인 후 제안

## 3. 원하는 결과

어떤 분위기나 느낌을 원하는지 고르세요.

- [ ] 밝고 깔끔하게
- [ ] 차분하고 고급스럽게
- [ ] 따뜻하고 친근하게
- [ ] 어둡고 집중되게
- [ ] 더 단순하게
- [ ] 현재 분위기를 유지하며 조금만 개선
- [ ] 잘 모르겠음

좋아하는 화면이나 사이트가 있다면 어떤 점이 좋은지 적어 주세요.

```
(예: 다른 서비스의 첫 화면처럼 큰 글씨와 여백이 좋다)
```

## 4. 반드시 유지할 부분

지금 디자인 중 없어지거나 바뀌면 안 되는 부분을 적어 주세요.

```
(예: 상단의 로고 위치와 색상은 그대로 유지)
```

- [ ] 현재 상태 유지
- [ ] 요청하지 않음

## 5. 바꾸면 안 되는 부분

이번 요청에서 건드리면 안 되는 것(다른 화면, 다른 기능, 설정 등)을 적어 주세요.

```
(예: 결제 화면은 건드리지 않는다)
```

- [ ] 요청하지 않음

## 6. 사용자가 직접 확인할 부분

바꾼 뒤에 사용자가 직접 눈으로 확인해야 하는 것들을 적어 주세요.

```
(예: 휴대폰 화면에서 버튼이 잘리지 않는지)
```

- [ ] 요청하지 않음

## 7. AI가 먼저 확인할 질문

- [ ] AI가 먼저 프로젝트 구조와 디자인 파일 위치를 확인한 뒤 안내해 주세요.
- [ ] 어떤 색상 조합이 어울리는지 몇 가지 선택지로 제안해 주세요.
- [ ] 변경 전과 변경 후 차이를 한눈에 볼 수 있게 정리해 주세요.
- [ ] AI가 먼저 확인 후 제안 (위 항목 대신 AI 판단에 맡김)

## 8. 최종 요청문

아래를 복사해서 사용 중인 AI Agent에 붙여넣으세요. `( )` 자리에 위 내용을 합쳐서 적어도 됩니다.

```text
이 프로젝트에서 다음 디자인 요청을 처리해주세요.

[현재 상황] (2번 항목에서 고른 불편 영역과 설명)
[원하는 결과] (3번 항목에서 고른 분위기)
[유지할 부분] (4번 항목, 없으면 "없음")
[건드리면 안 되는 부분] (5번 항목, 없으면 "없음")
[사용자 확인] (6번 항목, 없으면 "없음")

체크되지 않은 항목은 비워 두었습니다.
모르는 항목을 추측해 채우지 말고, 필요한 것이 있으면 먼저 질문해주세요.
확인한 프로젝트 구조만 기준으로 안내하고, 확인하지 못한 경로는 "확인 필요"로 표시해주세요.
```
