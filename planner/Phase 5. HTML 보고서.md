## Phase 5. HTML 보고서

Phase 4가 안정화된 뒤 진행한다.

처음부터 복잡한 프로젝트 지도를 만들지 않고, 정적 HTML 보고서 한 장부터 만든다.

```

reports/
└─ latest-report.html

```

화면구성: 

```

┌─────────────────────────────┐
│ 이번 작업 요약              │
├─────────────────────────────┤
│ 사용자 화면에서 달라진 점   │
├─────────────────────────────┤
│ 수정된 기능                 │
├─────────────────────────────┤
│ 변경 파일                   │
├─────────────────────────────┤
│ 위험 및 영향                │
├─────────────────────────────┤
│ 직접 확인할 항목            │
├─────────────────────────────┤
│ 다음 요청 만들기            │
└─────────────────────────────┘

```

이 단계까지는 서버가 필요 없다.

HTML 파일을 더블클릭해서 브라우저로 열면 된다.
