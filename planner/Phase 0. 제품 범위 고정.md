## Phase 0. 제품 범위 고정

# 대상 사용자

Codex를 사용해 프로젝트를 만들지만
코드와 개발 용어를 완전히 이해하지 못하는 사용자

# V0.1에서 해결할 문제

문제 1
Codex가 작업 후 어려운 개발 용어로 설명한다.

문제 2
사용자가 어떤 파일과 기능이 바뀌었는지 알기 어렵다.

문제 3
사용자가 다음 수정 요청을 정확하게 작성하기 어렵다.

# V0.1 결과물

Codex가 작업을 완료하면 이런 형식으로 보고해야 한다.

```
이번 작업 한 줄 설명

로그인 화면에서 비밀번호 표시 기능을 추가했습니다.

사용자 화면에서 달라지는 점

비밀번호 입력창 오른쪽에 눈 모양 버튼이 생깁니다.
버튼을 누르면 입력한 비밀번호를 확인할 수 있습니다.

수정된 기능

- 로그인 화면
- 비밀번호 입력창
- 입력값 표시 기능

수정된 파일

- src/features/auth/components/PasswordInput.tsx
  로그인 화면의 비밀번호 입력창입니다.

- src/features/auth/styles/password-input.css
  비밀번호 입력창의 모양을 담당합니다.

주의할 점

비밀번호 자체를 저장하거나 서버로 새롭게 보내는 변경은 없습니다.

직접 확인할 항목

1. 눈 버튼을 누르면 비밀번호가 보이는지
2. 다시 누르면 비밀번호가 가려지는지
3. 모바일 화면에서도 버튼이 정상적으로 보이는지

판정

직접 확인 후 승인 가능

```

이 출력이 안정적으로 나오면 Phase 0은 성공이야.
