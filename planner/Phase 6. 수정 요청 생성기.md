## Phase 6. 수정 요청 생성기

HTML에서 사용자가 원하는 부분을 선택한다.

```

기능: 로그인 화면

수정 대상:
☑ 로그인 버튼
☐ 입력창
☑ 오류 문구
☐ 로그인 처리 기능

요청 내용:
[버튼을 조금 더 크게 하고 오류 문구를 쉽게 바꿔주세요.]

```

그러면 다음 프롬프트를 만든다.

```

목표

로그인 화면의 버튼 크기와 오류 문구를 수정합니다.

변경 대상

- 로그인 버튼
- 오류 메시지

변경 금지

- 로그인 API
- 사용자 세션
- 데이터베이스
- 비밀번호 검증 방식

관련 파일

- src/features/auth/LoginForm.tsx
- src/features/auth/login.css

완료 조건

- 기존 로그인 기능 유지
- 모바일 화면 확인
- 오류 문구 확인
- 관련 테스트 실행

작업 전 현재 구조를 확인하고,
변경 예정 파일을 먼저 보고하세요.

```

초기에는 복사 버튼만 제공하면 된다.

Codex와 직접 연결하는 기능은 나중 문제다.
