# AGENTS.example.md

이 문서는 **예시**입니다. 실제 프로젝트의 AGENTS.md는 CLI나 Dashboard가 프로젝트 규칙에 맞게 생성하며, 사용자·프로젝트·경로 정보를 담지 않습니다.

아래는 저장소 규칙 파일의 일반적인 형태입니다.

```markdown
# <프로젝트 이름> 검증 저장소

- 이 저장소는 <목적>을 검증하는 프로젝트입니다.
- 코드 또는 문서를 변경한 후 <도구>를 사용합니다.
- 보고서 상태 체계는 <기준 문서>를 따릅니다.
- 테스트 기준은 <테스트 문서>를 따릅니다.
- 기존 사용자 변경을 임의로 되돌리지 않습니다.
- 확인하지 않은 결과를 사실처럼 보고하지 않습니다.
- 실제 시나리오 실행은 사용자가 별도로 요청할 때만 진행합니다.
```

## 실제 AGENTS.md와의 차이

- 실제 AGENTS.md는 해당 저장소의 규칙이므로 외부 검토 번들에는 이 예시만 포함됩니다.
- 실제 AGENTS.md는 공개 저장소에 커밋된 공개 제품 지침이면 포함될 수 있으며, 포함 여부는 Git 추적 여부와 제품 배포 목록을 기준으로 정합니다.
