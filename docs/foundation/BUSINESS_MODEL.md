# Business Model (공개본)

## 원칙

JuTell Core는 오픈소스이며 로컬에서 사용할 수 있다.

계정과 Cloud 없이 핵심 기능을 사용할 수 있다.

향후 선택형 Cloud·Premium 기능이 생길 수 있다.

유료 기능을 사용하지 않아도 로컬 Core는 계속 사용할 수 있다.

Telemetry는 명시적 동의가 있어야만 활성화할 수 있다.

---

## Core (무료)

- Skill
- Workflow
- Dashboard
- Report
- Review
- Diff

## Cloud (선택형 미래 기능)

- Cloud Sync
- Team Dashboard
- Community
- Marketplace
- Beta
- Premium Features

구체적인 가격, 매출 계획, 전환율 목표, 유료 기능 우선순위는

이 공개 문서의 범위가 아니다.
