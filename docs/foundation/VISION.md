# JuTell Vision

## Mission

JuTell의 목표는 AI를 더 똑똑하게 만드는 것이 아니다.

비개발자가 AI를 이해하고,
검증하고,
운영하고,
관리할 수 있도록 만드는 것이다.

---

## 우리가 해결하는 문제

AI는 코드를 잘 만든다.

하지만

- 무엇을 수정했는지
- 왜 수정했는지
- 다음 AI에게 무엇을 전달해야 하는지

설명하지 못하는 경우가 많다.

JuTell은 이 간극을 메운다.
