# Product Philosophy

## JuTell은 무엇인가

JuTell은 AI Agent가 아니다.

JuTell은

- Codex
- Claude Code
- OpenCode
- Cline

위에서 동작하는 Harness이다.

---

## JuTell이 하는 일

JuTell은

- 쉬운 설명
- Diff 해석
- 코드 리뷰
- 프로젝트 운영
- Workflow
- Report
- 용어 설명
- 요청 만들기 (사용자 → AI Agent 방향의 요청 템플릿)
- 로컬 사용량 측정 (선택형, 기본 꺼짐)

을 제공한다.

---

## JuTell이 하지 않는 일

모델을 만들지 않는다.

IDE를 만들지 않는다.

AI를 대체하지 않는다.

기존 Agent를 대체하지 않는다.
