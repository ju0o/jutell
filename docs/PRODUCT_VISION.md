# JuTell 제품 비전

## 출발점

비개발자가 AI와 함께 프로젝트를 만들 때 코드가 빠르게 바뀌어도 변경 의미, 검증 결과, 위험, 다음 요청을 이해하기 어려운 문제가 남습니다. JuTell은 AI에게 프로젝트를 맡기기만 하는 사람이 아니라, AI와 함께 자신의 프로젝트를 이해하고 운영하는 사람이 되도록 돕기 위해 만들어졌습니다.

## 핵심 철학

> AI가 프로젝트를 대신 소유하게 하는 것이 아니라, 비개발자가 AI와 함께 자신의 프로젝트를 이해하고 운영하게 합니다.

JuTell은 개발 용어와 근거를 없애지 않습니다. 필요한 용어를 쉬운 말로 설명하고, 사용자가 조금씩 익힐 수 있게 합니다. 사용자를 영원히 초보자로 남겨두는 것이 목표가 아닙니다.

## 다섯 기능 영역

| 영역 | 의미 | 현재 상태 |
|---|---|---|
| Understand | AI 작업, 화면 변화, 내부 변화와 파일 역할을 이해 | 쉬운 작업 보고와 주요 파일 설명 제공 |
| Verify | 사실·예상·미확인, 테스트·빌드·위험을 확인 | 보고서 규칙과 기술 검증 기록 제공 |
| Continue | 다음 AI 요청, 허용 범위, 완료 조건을 준비 | 보고서의 사용자 행동과 다음 단계 안내 제공. 자동 요청 생성은 미래 방향 |
| Plan | 목표, 기능, 순서와 우선순위를 구조화 | 제품 방향. 별도 기획 기능은 아직 미구현 |
| Operate | Profile, Feature, limits, 관리자, Skill, MCP, CLI를 운영 | 로컬 관리자, Skill, 선택형 MCP, CLI 제공 |

## 현재 기능

현재 구현된 범위는 쉬운 작업 보고, Profile·Feature·limits 설정, 호환 Skill, 로컬 읽기 전용 MCP, 로컬 관리자, Beta Journal, CLI 설치·상태·진단·제거입니다.

## 미래 방향

고급 코드 해석, 시각적 Diff, 다음 AI 요청 자동 생성, 프로젝트 기획, 운영 Workflow, 중앙 서버, 익명 Telemetry, 팀 기능은 향후 검토 대상입니다. 이 문서의 미래 방향은 구현 완료를 뜻하지 않습니다.

## 하지 않는 것

JuTell은 사용자를 추적하거나 프로젝트를 대신 소유하지 않습니다. 중앙 서버, 계정, 결제, 원격 Telemetry와 외부 서비스 연결은 현재 범위가 아닙니다.
