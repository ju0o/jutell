# Codex Beginner Bridge 개인 베타 계획

## 목적

개인 베타는 실제 Codex 작업에 Beginner Bridge를 반복해서 적용해, 보고서가 이해하기 쉬운지와 어떤 설정이 유용한지 확인하는 단계입니다. 외부 사용자의 통계나 공개 베타 통계를 만드는 단계가 아닙니다.

## 완료 기준

다음 조건을 모두 확인하면 개인 베타 계획을 정리할 수 있습니다.

- 서로 성격이 다른 실제 프로젝트를 최소 3개에서 사용합니다.
- `minimal`, `balanced`, `learning`, `detailed` 네 Profile을 각각 한 번 이상 사용합니다.
- 현재 Feature 8개를 실제 작업에서 켜거나 끄며 비교합니다.
- 전체 보고서 최소 20개를 읽고, 반복되는 불편을 묶어 기록합니다.
- 작업을 막는 치명적인 오작동이 반복되지 않습니다.
- 각 Feature를 유지할지, 기본 OFF로 바꿀지, 제거할지 판단할 근거가 생깁니다.

20개라는 수보다 실제 사용 상황과 반복되는 문제의 기록을 우선합니다. 특정 조건을 충분히 확인하지 못했다면 완료로 표시하지 않습니다.

## 사용 범위

### Profile

- `minimal`: 짧은 보고서가 필요한 작업
- `balanced`: 기본 비교 기준
- `learning`: 어려운 용어를 더 확인할 작업
- `detailed`: 복잡하거나 위험한 작업

### Feature

현재 공식 Feature 8개를 모두 검토합니다: 변경 요약, 사용자에게 보이는 변화, 내부 변화, 주요 파일, 용어, 검증 결과, 위험도, 사용자 행동. 실제 설정 이름과 예외는 [Feature Registry](../.agents/skills/beginner-bridge/references/feature-registry.md)를 기준으로 합니다.

## 매번 기록할 내용

- 사용한 Profile과 활성 Feature
- 작업 유형과 프로젝트를 식별하지 않는 별칭
- 보고서가 유용했는지
- 보고서가 너무 길었는지
- 어려웠던 용어와 이해하기 어려운 표현
- 숨기고 싶었지만 보고서에 필요했던 정보
- 꺼져 있었지만 필요했던 Feature
- 사실과 다른 것처럼 보였거나 오해를 부른 보고서
- 빠져서 중요했던 정보
- 다음 버전에 필요한 개선

기록은 [BETA_FEEDBACK_TEMPLATE.md](BETA_FEEDBACK_TEMPLATE.md)를 사용합니다. 실제 프로젝트 이름, 경로, Prompt, 코드, Git diff, 오류 원문, 비밀정보는 기록하지 않습니다.

## 성공 판단

개인 베타가 유용했다고 판단하려면 다음 근거가 있어야 합니다.

- 반복해서 쓸 수 있는 Profile·Feature 조합을 찾았습니다.
- 유지할 Feature와 기본 OFF 후보를 구분했습니다.
- 안전 정보와 중요한 미확인 사항이 계속 보고됐습니다.
- 보고서 길이와 이해하기 어려운 표현이 줄었습니다.
- 공개 베타를 준비할 때 필요한 설치·사용·개인정보 설명의 개선점이 정리됐습니다.

## 금지 사항

- 외부 사용자 통계가 있다고 주장하지 않습니다.
- 실제 사용 없이 V1 완료나 공개 베타 통과를 선언하지 않습니다.
- Telemetry 동의를 자동으로 얻거나 외부로 전송하지 않습니다.
- Prompt, 코드, AI 답변, 파일 경로를 자동 또는 수동 기록에 넣지 않습니다.
- 개인 베타 피드백만으로 제품 범위를 임의로 확대하지 않습니다.

## 공개 베타 전환 기준

공개 베타를 검토하기 전 다음을 별도로 확인해야 합니다.

- 로컬 관리자 기능이 구현됐다면 안정적으로 실행됩니다.
- 설정 변경이 잘못 저장되거나 기존 설정을 잃지 않습니다.
- Feature ON/OFF와 Profile 변경이 의도대로 적용됩니다.
- 로컬 기록을 전부 삭제할 수 있습니다.
- 개인정보와 기록 범위를 화면이나 문서에서 확인할 수 있습니다.
- 외부 전송이 없거나, 있다면 별도 동의와 전송 범위가 확인됩니다.
- 반복되는 불편의 우선순위가 정해졌습니다.
- 설치와 실행 절차를 실제로 따라 해봤습니다.
- README와 START_HERE를 처음 보는 사람이 이해할 수 있는지 확인했습니다.

원격 Telemetry나 중앙 서버는 공개 베타 전환의 필수 조건이 아닙니다.
