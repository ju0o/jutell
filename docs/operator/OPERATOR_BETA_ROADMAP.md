# 개인 베타 로드맵 (Operator Beta Roadmap)

현재 단계는 **개인 로컬 베타 준비**입니다. 아래 단계를 순서대로 진행하며, 각 단계의 완료 조건과 차단 조건을 확인합니다. 한 단계의 완료 조건이 채워지기 전에 다음 단계로 넓히지 않습니다.

## Stage 0 — 준비

- [ ] 이 저장소의 문서 위치와 로컬 기록 위치를 안다 ([파일 가이드](OPERATOR_FILE_GUIDE.md))
- [ ] 일일 체크리스트를 쓸 수 있다
- 완료 조건: 시작 가이드를 읽고 오늘 할 일을 고를 수 있음

## Stage 1 — 한 사람이 쓰기 시작

- [ ] 작은 작업 1개를 `balanced` Profile로 실행
- [ ] 결과를 베타 기록에 남김
- 완료 조건: 같은 작업을 두 번 이상 반복해 사용할 수 있고 기록이 남음
- 차단 조건: 설정이 저장되지 않거나 보고서가 생성되지 않음 → 기록하고 수정 대기

## Stage 2 — 실제 프로젝트에서 사용 (최소 3개)

- [ ] 3개 이상 실제 프로젝트에서 사용
- [ ] 프로젝트별로 베타 기록을 남김
- 완료 조건: 3개 프로젝트 모두에서 보고서가 나오고 기록이 남음
- 차단 조건: 특정 프로젝트에서 연결이 안 됨 → 증상을 기록하고 원인 확인

## Stage 3 — Profile 비교

- [ ] `minimal`, `balanced`, `learning`, `detailed`를 각각 최소 2회 사용
- [ ] Profile마다 길이 체감·이해도·다시 사용할 의향을 기록
- 완료 조건: 네 Profile을 비교한 기록이 남음
- 차단 조건: Profile 차이를 확인하기 전에 평가를 내림 → 기록을 더 쌓음

## Stage 4 — Feature ON/OFF

- [ ] Feature별 ON/OFF가 의도대로 적용되는지 확인
- [ ] 켠 Feature마다 기록을 남김
- 완료 조건: 활성 Feature 목록이 설정과 일치함
- 차단 조건: Feature가 꺼졌는데 보고서에 반영 안 됨 → 기록하고 수정 대기

## Stage 5 — 반복 문제 정리

- [ ] 심각도 높은 문제를 한 번 이상 만나면 기록함
- [ ] 두 번 이상 반복된 문제를 모아 정리
- 완료 조건: 반복 문제 목록이 정리되고 우선순위가 정해짐

## Stage 6 — 개인 베타 완료 보고 (V0.1 판정)

- [ ] 개인 베타 결과를 보고서로 정리
- [ ] 실제 사용에서 확인된 문제와 연결된 변경만 제안
- 완료 조건: 검증된 결과로만 판정. **실제 테스트 전에는 V0.1 통과를 선언하지 않음**
- 차단 조건: 검증되지 않은 예상으로 판정하려 함 → 실제 확인 기록을 다시 봄

## Stage 7 — 공개 베타 준비

- 완료 조건:
  - 개인 베타 완료 보고가 있고 V0.1 판정이 나옴
  - 공개 저장소 안전 검사가 통과함
  - 공개/로컬/비공개 기록 위치가 명확히 정리됨
  - 운영자 문서가 준비됨
  - 중앙 서버 기능이 필요 없다는 확인이 남음
- 차단 조건:
  - 중앙 서버나 원격 기능을 요구하는 변경이 먼저 진행됨
  - 피드백이 없는 상태에서 Feature가 늘어남
  - 제품 범위가 확인된 문제와 연결되지 않고 넓어짐

## 진행 원칙

- 피드백 없이 Feature를 늘리거나 제품 범위를 넓히지 않습니다.
- 새 Feature는 실제 사용에서 확인된 문제와 연결해 제안합니다.
- 현재 로컬 관리자 기능은 설정과 사용자가 직접 작성한 기록에 한정합니다.
