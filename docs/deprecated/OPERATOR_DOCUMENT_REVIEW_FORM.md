# 운영자 문서 검토 폼 (Operator Document Review Form)

문서 한 개를 검토할 때 아래 폼을 복사해서 사용합니다. 검토 대상은 공개 문서와 운영자 문서입니다.

```
# 문서 검토 기록

## 검토 대상
(파일 경로)

## 검토일
YYYY-MM-DD

## 확인 항목 (모두 체크)

- [ ] 1. 내용이 사실과 일치한다 (실제 동작·구현 기준)
- [ ] 2. 완성된 문장으로 쓰였다 (작업 메모·"나중에 적는다" 없음)
- [ ] 3. 미래 기능을 현재 구현처럼 서술하지 않았다
- [ ] 4. 구현된 범위와 일치한다 (확인하지 않은 결과를 사실로 쓰지 않음)
- [ ] 5. 비밀정보·경로·프로젝트 식별 정보가 없다
- [ ] 6. 링크가 정상이다 (깨진 링크 없음)
- [ ] 7. 다른 문서와 중복되는 내용이 없거나, 있어도 상호 링크로 연결된다
- [ ] 8. 공개/운영자/비공개 분류가 맞다
- [ ] 9. 다음 행동이 명확하다 (독자가 무엇을 하면 되는지)
- [ ] 10. 이 문서의 목적에 맞는 위치에 있다

## 검토 결과 상태 (하나 선택)

[ ] 초안 (작성 시작만 한 상태)
[ ] 작성 중 (아직 내용이 채워지는 중)
[ ] 검토 대기 (검토할 사람을 기다리는 중)
[ ] 승인됨 (검토 완료, 그대로 유지)
[ ] 수정 필요 (검토에서 수정 항목이 나옴)
[ ] 보관 (더는 갱신하지 않지만 남겨 둠)
[ ] 제거 대기 (삭제를 결정한 상태)

## 발견한 문제
(항목 번호와 함께 짧게. 예: "2. 작업 메모 문장 있음")

## 수정 여부
[ ] 이번에 수정함
[ ] 다음 작업에서 수정 (누가: ____)
[ ] 수정하지 않음 (이유: ____)

## 비고
(검토하면서 떠오른 의문. 검토 폼 자체에 답을 적지 않아도 됨)
```

## 사용법

1. 검토할 문서를 위 10개 항목으로 확인합니다.
2. 상태를 하나 고릅니다.
3. 문제가 있으면 `수정 여부`를 정합니다. 명백한 오류와 작업 메모는 바로 수정하고, 나머지는 판단이 필요한 항목으로 남깁니다.
4. 상태가 `수정 필요`이면 다음 행동과 담당자를 명확히 합니다.
