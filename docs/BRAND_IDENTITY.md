# JuTell 브랜드 정체성

## 브랜드 관계

- 상위 브랜드: `Ju0`
- 제품명: `JuTell`
- 공식 표기: `JuTell by Ju0`
- 제품 설명: AI와 만든 프로젝트를 이해하고 운영하게 해주는 오픈소스

## 공식 설명

JuTell은 비개발자가 AI 코딩 에이전트의 작업을 이해하고, 검증하고, 다음 작업을 요청하며, 프로젝트를 직접 운영할 수 있도록 돕는 오픈소스입니다.

영어 설명은 다음을 사용합니다.

> JuTell helps non-developers understand, verify, continue, plan, and operate projects built with AI coding agents.

## 슬로건

> AI는 코드를 만들고, JuTell은 사람이 그 코드를 이해하고 운영하게 합니다.

친근한 소개 영역에서는 다음 문장을 사용할 수 있습니다.

> AI가 뭘 했다는 건지 모르겠으면, JuTell이 다시 말해줍니다.

공식 정책과 안전 문서에는 친근한 문장만으로 제품을 설명하지 않습니다.

## 명칭 규칙

| 상황 | 권장 표기 |
|---|---|
| 첫 화면·문서 제목 | JuTell |
| 공식 소개 | JuTell by Ju0 |
| CLI | `jutell` |
| 이전 CLI | `beginner-bridge` 호환 별칭 |
| Skill 경로·ID | `.agents/skills/beginner-bridge/` 호환 경로 |
| MCP 도구 ID | 기존 ID 유지 |

`Codex Beginner Bridge`를 새 기능의 대표 이름으로 사용하지 않습니다. 기존 설치·기록·마이그레이션을 설명할 때만 사용합니다.

## 잘못된 표기

- `Jutell`, `JUTELL`, `Ju Tell`처럼 제품명을 임의로 나누거나 바꾸지 않습니다.
- JuTell이 아직 제공하지 않는 기획·운영 기능을 현재 기능처럼 쓰지 않습니다.
- Ju0와 JuTell을 서로 다른 제품처럼 설명하지 않습니다.

시각 로고, 색상 체계, 마케팅 사이트와 상표 등록은 이번 범위에 포함하지 않습니다.
